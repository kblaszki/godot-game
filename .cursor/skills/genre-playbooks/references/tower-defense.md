# Tower defense (lab)

## Sim

- Path waypoints or grid path; wave tables as data (`sim-data-resources`).
- Tower acquire/fire on FixedTick; economy gold/lives.
- Placement validity + path integrity checks (maze TD).
- Optional bot director (`sim-bot-ai`).

## App

- Grid/lanes (`godot-2d-presentation`); build menu HUD (`game-ui-ux`).
- Fire/leak SFX (`game-audio`).

## Compose

`sim-bot-ai` · `sim-data-resources` · `level-design` · `game-ui-ux` · `godot-2d-presentation` · `game-feel`
