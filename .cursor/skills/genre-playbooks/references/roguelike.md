# Roguelike (lab)

## Sim

- Grid entities, turn order, FOV, combat resolution (`sim-bot-ai` for enemies).
- Dungeon via `procedural-gen` + reachability; permadeath run state.
- Seed in save (`save-systems`).

## App

- Tile/ASCII or 2D sprites from grid (`godot-2d-presentation`).
- Log/HUD (`game-ui-ux`); optional juice on hit.

## Compose

`procedural-gen` · `sim-bot-ai` · `sim-data-resources` · `save-systems` · `level-design` · `game-feel` · `godot-2d-presentation`
